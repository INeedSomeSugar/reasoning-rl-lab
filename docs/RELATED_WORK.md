# 方法定位与阅读路线

本项目研究一个可检验的工程与算法问题：探测模型在训练题上的成功率，再优先采样中等成功率题目，能否在共同计算预算下超过均匀采样？这是对课程学习、自适应数据选择和可验证奖励训练的实现与检验。下面是与设计直接相关的原始论文阅读记录；不构成系统查新，不作新算法声明。

|原始来源|与本项目的关系|阅读后需要区分的设计|
|---|---|---|
|Bengio等，[Curriculum Learning, ICML 2009](https://icml.cc/Conferences/2009/papers/119.pdf)|通过训练样本的呈现顺序或分布影响学习，是较早的课程学习研究|本项目使用当前成功率和中间难度权重，没有固定的由易到难阶段|
|Shao等，[DeepSeekMath](https://arxiv.org/abs/2402.03300)|GRPO的原始方法来源|本项目固定TRL实现，显式记录损失、归一化、KL及截断，采用beta=0的简化配置|
|Yu等，[DAPO v2，3.2节](https://arxiv.org/html/2503.14476v2#S3.SS2)|讨论组内全对/全错时优势为零，以及通过采样维持有效训练信号|DAPO过采样后过滤全对/全错组，填充训练批次；本项目先单独探测，再按平滑成功率加权抽题，仍可能得到零方差组|
|Hu等，[LoRA](https://arxiv.org/abs/2106.09685)|冻结骨干，只训练低秩增量|低显存验证依赖量化骨干与LoRA组合，实际可训练参数、梯度和重载误差需实测|

2026-11-05已打开ICML会议原文和DAPO v2原文，核对上述课程分布与动态采样的定位。其余来源和固定库版本见[SOURCES.md](SOURCES.md)。论文报告的性能不用于本项目结果表。

## 从公式到本项目的可检验假设

若单题每次生成独立、正确概率为p，G个二值奖励中有正有负的概率为

\[
P_{mixed}(p,G)=1-p^G-(1-p)^G.
\]

本项目采用`g(p)=4p(1-p)`。它在p=0.5处最大；G=2时与混合组概率成比例。当前G=4时它是解释清楚的中间难度启发式，不能据此声称最优采样，也不能把更高混合组比例直接等同于更高测试正确率。截断loss mask、梯度方向和训练题迁移都会影响实际收益。

K=2、Jeffreys先验0.5时，p估计只有1/6、1/2、5/6三档；首尾两档的g值相同。加入25%均匀份额后，权重差异进一步减弱。单次刷新后的变化可能来自采样噪声，应结合`probe_uncertainty.csv`中的实际成功次数、Beta后验标准差和权重变化看；这些后验量依赖独立伯努利假设，不能解释成校准过的模型能力区间。

## 当前日志给出的研究线索

首轮16题池、8步、seed13的C/D/E都只实际抽到5道不同题。动态组两次完整探测的有效池大小约15.36和15.70，说明初版权重分布相当平缓；它花费约70.6%的GRPO时间进行探测，混合奖励组每总GRPO分钟约0.071个。这里总时间包含验证，且各组实际时间不同，不能据此作同预算效益结论。
